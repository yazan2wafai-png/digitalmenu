# Digital Menu — Project Overview

Multi-tenant digital menu SaaS. One shared backend serves multiple restaurant
tenants, each with its own frontend. First/demo client: **Baltazar**
(burger place, Karaköy). A second tenant frontend exists for **Erenköy**.
The same codebase also houses the **NFC My Place** marketing/e-commerce site
(sells NFC+QR review cards, menu stickers, and admin-panel access — one of
its 3 products IS this digital menu product).

Moved over from Google Antigravity (Gemini sub-agents did the implementation
work there). Working with Claude going forward.

## Repo layout

This is a plain folder of independent Node projects (no pnpm workspaces /
turborepo) — `cd` into a subproject before running its scripts.

| Folder              | What it is                                    | Stack                                              |
|----------------------|------------------------------------------------|-----------------------------------------------------|
| `backend/`           | Shared multi-tenant API                        | NestJS 11, Prisma 5 + PostgreSQL, JWT auth, pnpm    |
| `frontend/`          | Main tenant-facing menu site (Baltazar + super-admin) | Next.js 16 (App Router), React 19, Tailwind        |
| `frontend-erenkoy/`  | Second tenant frontend (Erenköy)                | Next.js (App Router)                                |
| `admin-panel/`       | Restaurant owner control panel (photos, prices, categories) | Next.js (App Router)                        |
| `landing-page/`      | NFC My Place marketing/sales site, incl. a 3D product customizer | Next.js, Tailwind, Framer Motion, react-three-fiber/drei |

## Dev commands

Backend:
```
cd backend
pnpm install
cp .env.example .env   # fill in DATABASE_URL / JWT_SECRET
pnpm start:dev          # nest start --watch
```

Any of the Next.js apps (`frontend`, `frontend-erenkoy`, `admin-panel`, `landing-page`):
```
cd <folder>
npm install   # or pnpm, check for a lockfile
npm run dev
```

## Backend env vars (see `backend/.env.example`)
- `DATABASE_URL` — Postgres connection string (Docker Compose setup available: `docker compose up -d`)
- `JWT_SECRET` / `JWT_EXPIRES_IN`
- `BASE_URL` — for constructing public file URLs (local upload storage)
